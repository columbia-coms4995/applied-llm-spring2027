# Applied Large Language Models · Spring 2027

Columbia University, Department of Computer Science. Instructor: Dr. Spencer W. Luo.

Course website: https://columbia-coms4995.github.io/applied-llm-spring2027/

The website includes the course outline, grading, and course information. Lecture 1 slides and notebook are available; later lecture materials will be linked as they are released.

## Website files

This is a static HTML, CSS, and JavaScript website. GitHub Pages serves the repository root from the `main` branch. No build step or package installation is needed.

To preview locally, run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000/`.
